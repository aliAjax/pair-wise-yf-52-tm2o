# pair-wise-yf-52 戏剧排练台词版本与舞台提示管控

## 源提示词摘要
导演、编剧、舞台监督和演员共同维护不同版本的剧本、角色台词、上下场提示、道具与灯光音效提示。编剧提交后需逐条合并，演员可查看最新版并标记疑问；支持版本对比、单条采纳、批注、冲突处理、排练模式、大字号提词和断网缓存。

## 演出运行版（本轮闭环）
- 把当前剧本冻结成「演出运行版」：角色台词与舞台提示各自带执行顺序（seq）。
- 舞台监督确认顺序变化（删台词/删提示/换场序）后，未执行项作废重算，已执行项保留原顺序；顺序版本号 +1。
- 灯光、音效、场务离线回执按设备序号合并对齐；同一回执 id 重复上传只算一次。
- 断网恢复后从断点（uploadCursor）继续上传，批量推进；迟到回执（顺序版本已变更）只入历史，不盖到新顺序上。
- 岗位隔离：场务看不到灯光口令（显示为遮挡），舞台监督可见。
- 演出结束后仍可按版本查询已执行、已作废与回执记录。

## 技术栈
Angular + TypeScript + Angular Material + NgRx + Angular Router + RxJS + Angular CDK + Transloco。

## 已实现闭环
- 剧本版本和导演修订的创建、切换与版本差异摘要。
- 角色台词、舞台提示的采纳、退回和待确认状态。
- 排练模式、在线/离线切换与 localStorage 持久化。
- 未确认内容保留在草稿版本中，不会自动混入已采纳版本。
- 演出运行版冻结、执行顺序与顺序变更作废重算。
- 离线回执队列、断点续传、按设备序号合并、重复回执去重与迟到回执隔离。
- 舞台监督/场务岗位视角（灯光口令对场务遮挡）与演出结束后的版本执行记录。
